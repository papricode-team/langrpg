# Agent instructions

glotworld is a German-learning story RPG: a Phaser 4 + Vite frontend in `web/`, a Go service in `server/`, content and asset tooling in `scripts/`, and authoring sources in `content/` and `art/`. The README describes features and the project map; this file covers how to work in the repository.

## Verify before every push

There is no hosted CI. Checks run locally, and nothing goes to `main` until they pass.

```sh
npm ci
npm run verify
```

`npm run verify` runs, in sequence: the content bundle build, `gofmt`, `go vet`, `go test -race` against PostgreSQL, lint, `npm run check`, Vitest, the tooling tests, asset regeneration with a drift check on generated files, the dialogue and i18n audits, the production build and the distribution budgets. It prints a summary and writes `output/verify-summary.json`.

- Add `-- --ui` for the UI font floor and screenshot check. Screenshots go to `output/ui-screenshots`, never to the tracked gallery.
- Add `-- --docker` to build the runtime image. It needs a running Docker daemon; start OrbStack with `orb start` and stop it again afterwards.
- `-- --no-go` or `-- --no-web` skip a half while iterating, but a push needs the full run.
- Go integration tests use `TEST_DATABASE_URL` when set. Otherwise the script starts a disposable PostgreSQL when `initdb` is installed (`brew install postgresql@18`). If neither is available the Postgres tests skip; say so when reporting.
- Report failures with their output. Do not loosen a test, timeout or budget to get a green run without saying so.

`npm run release:check` adds the native-reviewer gate for word maps. It is a release step and fails until every sentence has a reviewer, so it is not part of `verify`.

## Worktrees

- Run `npm ci` in a fresh worktree; `node_modules` is per checkout and goes stale.
- Worktrees hold LFS pointers, not images. Art tests fail with "unsupported image format" until you run `git lfs checkout art/source art/proofs`, which copies from the local LFS cache without network.
- The git stash is shared with every other worktree and session. Use a temporary commit instead of `git stash`.

## Content

- `content/source.json` is the only copy of quests, characters and chapters. `web/src/content.ts` holds types and empty registries. Node tools read the data through `scripts/content-source.mjs`; Vitest through `web/src/test-support/authored-content.ts`.
- Never import learning data (answers, translations, quest text) into browser code as JSON. `scripts/content-runtime-plugin.mjs` replaces those registries with the authenticated content API and fails the build if private data or test support reaches the bundle.
- `server/content.json` is generated by `node scripts/build-content.mjs` and is gitignored. `content_ids.json` and `content/published-content-ids.json` are committed identity catalogs; keep both.
- Generated files listed in `scripts/verify.mjs` must be committed after `npm run assets` regenerates them.

## Server

- `package main` holds HTTP wiring and handlers. Storage, presence, billing, avatars, migrations and metrics live in `server/internal/*`.
- Schema changes are new numbered files in `server/migrations`. Never edit a migration that has been applied; its checksum is verified at startup. `server/README.md` has the workflow.
- Rate limits key on `clientIP`, which honours forwarding headers only from `TRUSTED_PROXIES`.
- Guest sessions never expire, because the token is a guest's only credential. Sessions of accounts with an email expire after `SESSION_IDLE_DAYS`.
- Never call Creem while holding an account lock: fetch first, then apply under the lock only if the purchase ledger is unchanged.
- `/metrics` requires `METRICS_TOKEN`. Label HTTP metrics by route pattern, never raw path.

## Frontend

- One Phaser scene per mode. Reset every per-run field in a scene's `init()`; field initialisers run only once per instance.
- Encounter dialogs that load before they open go through `openAsyncDialog` in `web/src/dialog-session.ts`.
- Gameplay modules must not import editor modules (`world-edit-*`, `admin-*`). Keep the `web/src` import graph free of cycles; `world-patch.ts` exists so `scene-data.ts` does not depend on editor code.

## Art and repository

- Source paintings and proofs are Git LFS (`.gitattributes`). Add a pattern before committing a new kind of master art.
- Each file in `web/dist/assets` must stay under the 2 MB budget in `scripts/check-budgets.mjs`.
- Commit messages describe the change in plain sentences. Merge the latest `main` into your branch and rerun `npm run verify` before pushing to `main`.
