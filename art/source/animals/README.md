# Painted town animals

These masters replace the rejected procedural cartoon drawings. The built-in ImageGen tool generated dog, cat, chicken and sheep sheets against the existing world screenshot (`art/proofs/poses/wave/world-bea-wave-browser.png`) and painted resident identity (`art/source/resident-actions/anne-reference.png`). The dog sheet supplied the layout and painting reference for the other species. Exact prompts are retained in `*-prompt.txt`; no CLI/API fallback was used.

Each native 1182 × 1330 sheet contains 72 poses: three distinct breeds, each with 24 poses in three rows of eight. The first row has four southeast walking phases and four northeast walking phases; horizontal mirroring provides the western directions. The second row has two idle, two sleeping and four foraging poses. The third row has four contented/petted poses and four alert/refusing poses. Chickens use the foraging poses to peck at scattered feed. Only cats enter the refusing state.

The initial calico changed coat in its four refusing poses. `cat-repair.png` restores those four cells. Only those cells are selected from the repair; the other 68 remain from the original master. Every export record names its source and hashes both inputs.

`node scripts/prepare-animal-art.mjs` (also included in `npm run assets -- --art`) finds whole alpha silhouettes rather than cutting through uneven generated gutters. It preserves one isotropic scale per breed, measures the grounded foot position and registers all frames at (64, 110) in 128 × 128 cells. Sleeping poses retain their naturally lower height. The exporter rejects missing, merged or clipped silhouettes and runtime-cell overflow. It reuses the resident exporter’s narrowly defined cleanup of saturated chroma noise at alpha 1–4; ordinary antialiasing remains untouched.

Runtime atlases and frame JSON live in `web/public/assets/animals/`. They load and release with each story town. No atlas is drawn at runtime. The quality pipeline keeps the atlas cell resolution: these small figures cannot be halved again merely because the full sheet exceeds 256px. Individual sheets are below the existing 2 MiB budget.

Visual review uses `/qa/animals.html`, which runs the actual WorldScene with terrain, player, residents, camera, navigation, lighting and interactions. Run `node scripts/check-animals.mjs` against the local development server, or set `ATLAS_UI_URL`. Evidence is saved in `output/ui-screenshots/animals-world-*.png`, not the tracked gallery. The browser check covers all 288 distinct poses, all 36 placements, real scene interactions, reduced motion, terrain-only visibility and map restarts. Behavior is ambient and local to a visit; feeding does not spend inventory, and petting does not grant rewards.
